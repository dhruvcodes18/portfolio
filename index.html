CASE 01 • VOICE TRUST & SECURITY (AUG 2026–PRESENT)

Multilingual Audio Deepfake & Sentiment Intelligence

PyTorch • Whisper • Wav2Vec2 • Flask

The Challenge: AI voice-cloning scams increasingly target regional Indian speakers, where single-modality detectors break down.

The Strategy & Solution: Engineered a 3-module real-time pipeline with a custom Gated Multimodal Fusion Network balancing acoustic prosody against English, Hindi, and Marathi transcripts.

CASE 02 • FINTECH RISK TOPOLOGY (OCT–DEC 2025)

Financial Fraud Detection via Graph Neural Networks

Python • PyTorch Geometric • Graph ML

The Challenge: Row-by-row tabular fraud classifiers miss coordinated money-laundering rings across linked accounts.

The Strategy & Solution: Modeled financial transactions as relational graphs in PyTorch Geometric, applying node classification to expose high-risk anomalous clusters.

CASE 03 • TALENT INTELLIGENCE (FEB–MAY 2026)

Automated JD-to-Resume Semantic ATS Engine

Python • NLP • Pandas • Ranking Algorithms

The Challenge: Rigid keyword filters in legacy hiring pipelines reject high-fit engineering candidates.

CASE 04 • CREDIT DECISIONING (JAN–MAR 2025)

Supervised Loan Risk Classification Pipeline

Python • Scikit-Learn • Pandas • Seaborn
